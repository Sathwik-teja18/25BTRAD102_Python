# Lab Exercise 11: Log File Reader Program

## Problem Statement
Develop a Python program to read a log file, identify specific keywords such as ERROR, WARNING, and INFO, and summarize the number of occurrences of each category.

## Critical Thinking (CT)
Analyze log contents, design suitable search and counting logic, handle missing or empty files, and verify the accuracy of results.

## Real World Exposure (RWE)
Apply the program to a sample application log and explain how it helps identify errors and monitor system activity.
