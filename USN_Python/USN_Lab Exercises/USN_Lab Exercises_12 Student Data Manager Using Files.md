# Lab Exercise 12: Student Data Manager Using Files

## Problem Statement
Develop a Python program to store, retrieve, search, update, and display student records using file operations.

## Critical Thinking (CT)
Design appropriate record-management logic, select suitable file operations, validate inputs, and test data retrieval and updates.

## Real World Exposure (RWE)
Apply the program to a college student-record management scenario and explain its usefulness in maintaining student information.
