# Lab Exercise 13: CSV-Based Payroll Management System

## Problem Statement
Develop a Python program to read employee records from a CSV file, calculate gross salary and applicable deductions, and generate salary summaries.

## Critical Thinking (CT)
Analyze payroll requirements, design calculation logic, process CSV records, validate data, and verify salary calculations.

## Real World Exposure (RWE)
Apply the program to a sample organization's payroll process and interpret the generated salary summaries.
