# Lab Exercise 15: Library Management System

## Problem Statement
Develop a Python program using classes and objects to manage books, issue and return books, and maintain availability status.

## Critical Thinking (CT)
Identify suitable classes and attributes, implement methods, apply inheritance where appropriate, and test book availability and issue/return conditions.

## Real World Exposure (RWE)
Simulate library operations and demonstrate how the system supports book tracking and efficient resource management.
