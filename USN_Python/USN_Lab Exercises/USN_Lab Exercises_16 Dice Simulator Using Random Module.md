# Lab Exercise 16: Dice Simulator Using Random Module

## Problem Statement
Develop a Python program that simulates rolling one or more dice using Python's random module. Allow repeated rolls and display the outcomes.

## Critical Thinking (CT)
Select suitable random functions, design the simulation logic, test repeated trials, and analyze the frequency of possible outcomes.

## Real World Exposure (RWE)
Relate the simulation to board games and probability experiments; interpret the observed outcomes across multiple rolls.
