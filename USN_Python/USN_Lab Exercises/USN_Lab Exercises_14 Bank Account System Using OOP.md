# Lab Exercise 14: Bank Account System Using OOP

## Problem Statement
Develop a Python program using classes and objects to manage bank accounts. Implement deposit, withdrawal, balance enquiry, and transaction validation.

## Critical Thinking (CT)
Design appropriate classes and methods, apply encapsulation, analyze transaction conditions, and test invalid transactions and insufficient balances.

## Real World Exposure (RWE)
Simulate routine banking transactions and explain how object-oriented programming supports account management and data protection.
