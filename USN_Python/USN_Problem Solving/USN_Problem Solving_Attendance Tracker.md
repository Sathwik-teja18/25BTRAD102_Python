# Mini Project: Attendance Tracker

## Problem Statement
Develop a Python-based attendance tracker for a class using lists and dictionaries. The application should store student names and attendance status, allow attendance records to be added or updated, display attendance details, and calculate each student's attendance percentage.

## Expected Functionalities
- Store student names and attendance records using suitable Python data structures.
- Add students and update their attendance status.
- Display attendance records in an organized format.
- Calculate attendance percentages and identify students below a specified attendance threshold.
- Test the program using different attendance scenarios.
