# Mini Project: Sales Data Analyzer

## Problem Statement
Develop a Python-based sales data analyzer using lists and dictionaries to manage product names, quantities sold, and prices. The application should calculate total sales, identify the highest-selling product, and summarize product-wise sales performance.

## Expected Functionalities
- Store product details and sales information using lists and dictionaries.
- Add or update product sales records.
- Calculate total sales and product-wise revenue.
- Identify the highest-selling product and compare product performance.
- Test the program using different sales datasets and interpret the results.
